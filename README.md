# Food Delivery Management System 

A console-based backend application built using **Java, JDBC, and MySQL** to simulate a basic food delivery platform.

##  Features

* View Restaurants
* View Menu by Restaurant
* Place Orders
* View Customer Orders
* Add Reviews & Ratings


#  Technologies Used

* Java
* JDBC
* MySQL


#  Concepts Implemented

## SQL

* JOINs
* Subqueries
* Views
* Stored Procedures
* Triggers
* Transactions

## JDBC

* Connection Handling
* Statement
* PreparedStatement
* ResultSet
* executeQuery()
* executeUpdate()
* Generated Keys
* Transaction Management

## Java

* OOP Concepts
* Service-Based Architecture
* Exception Handling
* Scanner Input Handling
* switch-case Menu System

#  Functionalities

## OrderService
